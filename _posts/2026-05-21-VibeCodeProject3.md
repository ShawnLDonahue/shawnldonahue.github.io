# Vibe Coding Project: Orbital Ascension Game 
## [View the live demo here](https://shawnldonahue.github.io/Project_Vibe_III/).

### Does not have mobile touch capability in this version - WASD / Arrows Only

Decided to loosen the reigns and blowoff some steam with a less-than-productive vibe-coded game. 
The repo is actually hosting the fourth iteration as I had to fine tune some code and rework the engine.
Some of this work is just to test the limitations and capabilities of a github hosted application.

## AI Generated Summary of My Prompt

```bash
- Create a single-file HTML game demonstrating the full potential of HTML, CSS, and JavaScript
- The game should be visually impressive, interactive, and inspiring, not a basic demo
- Use no external libraries or assets — everything must be self-contained
- Player controls an orange spaceship rendered with canvas drawing (not images)
- Include clear splash-screen instructions before gameplay begins
- Gameplay loop must be fully functional (movement, shooting, enemies, progression)
- Enemies should be red, aggressive shapes (e.g., ninja-star–like, pointed designs)
- Power-ups should be cyan orbs that upgrade the player when collected
- The weapon system should incrementally evolve, including:
  - Faster fire rate
  - Larger projectiles
  - Multiple guns across the ship
  - Eventually firing in all directions (360°)
- Add a progression-based upgrade system / upgrade tree tied to collected power
- Include large, visually distinct bosses that are easy to identify
- Bosses should come in multiple shapes and styles, not just one type
- Ensure the game works on desktop and mobile, including touch controls
- Everything must be provided in one large complete code block
- The final result should feel like a real arcade-style game prototype, not a toy example
```
